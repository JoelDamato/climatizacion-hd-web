# Climatización HD · sitio web

Sitio estático (HTML + CSS + JS, sin build). Se edita directo:

- `index.html` — portada · `nosotros/index.html` — nosotros
- `estilo.css` — estilos · `app.js` — interacciones y formulario de GHL
- `img/` — imágenes · `vercel.json` — redirecciones de las URLs viejas
- `llms.txt`, `llms-full.txt`, `robots.txt`, `sitemap.xml` — SEO y buscadores de IA

Para verlo local: abrir `index.html` o `npx serve .`
Proyecto de Vercel: `climatizacion-hd`.
